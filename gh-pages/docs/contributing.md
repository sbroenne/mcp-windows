# Help improve Windows MCP

You do not have to write code to help.

## Report a problem

Follow the [problem-reporting advice](troubleshooting.md#report-a-problem).
Clear steps and an error message make a report easier to investigate.
Do not include private documents or account information.

## Suggest clearer instructions

If a page is confusing or a setup step is missing,
[open an issue on GitHub](https://github.com/sbroenne/mcp-windows/issues/new/choose).
Include the page address and explain where you got stuck.

## Contribute code

The [developer contribution guide](https://github.com/sbroenne/mcp-windows/blob/main/CONTRIBUTING.md)
covers building the project, writing tests, and submitting a change.
Desktop tests can take control of the mouse and keyboard, so read that guide
before running them.

## Report security concerns privately

Use [GitHub's private security report](https://github.com/sbroenne/mcp-windows/security/advisories/new)
rather than a public issue.
